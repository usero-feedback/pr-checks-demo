This page exists to be measured. On every pull request in its repository, Usero PR checks loads the pull request's version and main's version back to back, then comments on the pull request with what changed.

The page is small on purpose: one image, one block of text, no scripts. That makes the image the largest thing on screen, so a heavier image moves Largest Contentful Paint by an amount you can predict from its size.
